# Demonstration walkthrough

The login screen displays student, tutor/teacher, and administrator credentials. You can also open each role with a single click.

1. **Administrator:** Add a fictional student, enroll the student in a group, create an assessment or record a tuition charge, and review the reporting screens.
2. **Tutor / teacher:** Switch accounts using **Try another role** in the top bar. Open assigned groups, mark attendance, and update grades.
3. **Student:** Switch to the student account. Review the personal course, attendance, grades, announcements, and fees screens.
4. **Language and appearance:** Use the ESP/EN control with the Spain/England flags and the sun/moon switch; navigate through several pages to verify both themes.
5. **Persistence:** Refresh the page to confirm edits remain for the current tab. Administrators can restore the original fictional records with **Reset demo**.

The dataset is synthetic. Do not enter real customer, student, identity, or payment information into the demo.
